# プロジェクト概要書 (PROJECT.md)

## プロジェクト名
**みことばの庭 (seisho-tsudoku-app)**

## 目的・ビジョン
クリスチャンや求道者が、日々の聖書通読を無理なく、喜びと平安をもって継続できる環境を提供する。
「義務感や挫折感」から「植物が育つような日々の静かな楽しみ」へと聖書通読の体験を転換する。

## コアメッセージ
- 「今日開いた一冊が、あなたの一年をつくる。」
- 「焦らなくていい。開いた分だけ、進んでいる。」
- 「昨日読めなくても、今日また開けばいい。」
- 「急がず、比べず、自分のペースで。」

## 想定ユーザーと利用シーン
1. **主ユーザー**: 井上聖嗣牧師（新発田いのちのパンチャーチ）、教区・教会の信徒、求道者。
2. **利用環境**: 主にスマートフォンの Safari から「ホーム画面に追加」（PWA / WebClip）して利用。
3. **利用時間帯**: 毎晩の就寝前（「夜の儀式」としての一日の振り返り）、または毎朝の静思の時。

## 通読プラン構成
1. **三つ撚りの糸 (streams)**
   - 平日5日間ペース（年間260日）
   - 旧約歴史書、詩篇・知恵の書、新約書簡の3系統を並行して読み進める。
   - 週末（土日）はバッファ（追いつき）または教会礼拝に充てる。
2. **アルファからオメガへ (full)**
   - 毎日ペース（年間365日）
   - 創世記から黙示録まで、聖書66巻を最初から順番に読破する。
3. **走るべき道 (nt90)**
   - 毎日ペース（90日間）
   - 新約聖書全27巻を3ヶ月で集中して読み切る。
4. **軽やかなくびき (gospel)**
   - 毎日ペース（60日間）
   - 四福音書（マタイ、マルコ、ルカ、ヨハネ）を2ヶ月かけてじっくり味わう。初心者向け。

## 今後の機能拡張ロードマップ
- **フェーズ1（現在完了）**: 聖書通読トラッカーの基本機能、iOS最適化、Vercelデプロイ。
- **フェーズ2（次期開発）**: 「夜の儀式」統合（一日の振り返り日記欄 ＋ 明日の最重要タスク3つ）。毎晩約30分で「振り返り → 聖書通読 → 明日のタスク設定」を完結させる。
- **フェーズ3**: データバックアップ機能（JSONエクスポート/インポート、またはクラウド同期）。
