# 設計決定記録 (DECISIONS.md)

本ドキュメントは、プロジェクト「みことばの庭」における重要な設計判断とその背景（Architecture Decision Records: ADR）を記録したものです。

---

## ADR-001: 単一ファイルHTML (Single-File Web App) の採用
- **決定**: ビルドツールやUIフレームワークを用いず、`index.html` 単一ファイル（HTML/CSS/JS内包）で構築する。
- **背景**: サーバー管理や複雑なビルドパイプラインの保守コストを極小化し、Vercel等へ置くだけで即座に動作する軽量性を最優先した。
- **影響**: 開発時は `index.html` の特定部分のみを局所的に編集する規約が必要。

## ADR-002: スタンプカレンダー・実績バッジの廃止と「庭の成長」への一本化 (Commit `73ff820`)
- **決定**: 初期に存在したスタンプカレンダーと多数の実績バッジを廃止し、基本統計（1行）＋「庭の成長（レベルロードマップ）」に一本化した。
- **背景**: バッジやスタンプは画面を過密にし、利用者に「埋めなければならない」というプレッシャー（義務感）を与える懸念があった。
- **影響**: UIが劇的にスッキリし、「静かに木を育てる」という統一された情緒的体験に収斂した。安易なバッジ機能の再追加は避けること。

## ADR-003: 「今日の通読」と「たまっている分（バックログ）」の分離 (Commit `edd5f15`)
- **決定**: 遅れている分が終わるまで今日の分が表示されない旧仕様を改め、常に最上部に「今日の分」を表示し、遅れ分は折りたたみ可能な「たまっている分」として別セクションにした。
- **背景**: 聖書通読で最も多い挫折パターンは「過去の遅れが山積みになり、今日何を読むべきかわからなくなって諦める」こと。
- **影響**: 常に今日の分から始められ、気が向いた時にバックログを解消できるため、心理的ハードルが大幅に下がった。

## ADR-004: 下部ナビゲーションの浮遊ピル型デザインへの刷新 (Commit `1a39c59`)
- **決定**: 画面最下部に固定されたベタ塗りのバーから、画面下部中央に余白を持って浮遊する丸型ピル型バーに変更した。
- **背景**: スマートフォン（特にiPhone）で片手操作する際、最下部バーだと誤タップやジェスチャーバーとの干渉が起きやすく、また文字が小さすぎて見づらかった。
- **影響**: タップ領域が広がり、現在地（今日／成長／一覧）の視認性が向上。ホーム画面アプリとしての洗練度が高まった。

## ADR-005: 「新改訳2017」への外部リンク（prs.app）の統合 (Commit `3669b6d`)
- **決定**: 各箇所の横に外部リンクアイコンを設置し、タップで「ともに聴く聖書」（prs.app）の新改訳2017テキストを開くようにした。
- **背景**: 著作権の関係上、聖書本文データを直接アプリ内に内包するのは困難だが、ユーザーが聖書本文をすぐに読めないと利便性が落ちる。
- **影響**: 外部Webサービス（prs.app）をシームレスに活用することで、著作権をクリアしつつ公式な新改訳2017の本文閲覧・音声再生が可能になった。

## ADR-006: プラン開始日の事後変更とプラン削除機能の追加 (Commit `661949a`)
- **決定**: 設定モーダル内で、プランの開始日を後から変更できるようにし、不要になったプランの完全削除フローを追加した。
- **背景**: 開始日を間違えて登録した場合に修正できず、また試行錯誤で作成したプランを整理できなかった。
- **影響**: 読了記録（日番号）を保持したまま開始日を前後にずらすことが可能になり、運用の柔軟性が向上した。

## ADR-007: DOM状態保持によるチェック時のアコーディオン開閉維持 (Commit `5762846`)
- **決定**: 全日程リストやバックログでチェックを付けた際、再描画前に現在の開閉状態（`details[open]`）をメモリに退避し、再描画後に復元するロジックを導入した。
- **背景**: 再描画のたびに開いていたアコーディオンが閉じてしまい、連続してチェックする際の操作性が著しく悪化していた。
- **影響**: 開閉状態を気にせずスムーズに連続操作できるようになった。

## ADR-008: 「夜の儀式」統合方針 (Claude最終セッション)
- **決定**: 聖書通読単体アプリから、毎晩約30分で「一日の振り返り（日記）→ 聖書通読 → 明日のタスク決め（最重要3つ）」を行う「夜の儀式」アプリへと統合・発展させる方針。
- **背景**: 井上牧師の多忙な牧会・事務・教育生活の中で、就寝前の30分を心静かなリフレクションと翌日の備えの時間にするため。
- **未決事項**: 日記やタスクの保存先（`localStorage` のみか、Supabase/Notion等のバックエンド連携か）はユーザーと要確認。
