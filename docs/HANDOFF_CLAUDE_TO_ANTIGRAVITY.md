# Claude → Antigravity Handoff

## 1. Project Overview
- **アプリ名**: みことばの庭（seisho-tsudoku-app）
- **リポジトリ**: `bdmsw788/seisho-tsudoku-app`
- **目的**: 毎日の聖書通読を無理なく、喜びをもって継続・習慣化するためのWebアプリケーション。
- **想定ユーザー**: 井上聖嗣牧師本人、教会員、求道者。iPhone等のスマートフォンでSafariから「ホーム画面に追加（PWA/WebClip）」して使用することを主眼に置く。
- **コアメッセージ**: 「今日開いた一冊が、あなたの一年をつくる。」「急がず、比べず、自分のペースで。」「小さな種が、いつか大きな木になる。」

## 6. Claudeが採用した技術構成
- **アーキテクチャ**: 単一ファイルHTML（Single File HTML: `index.html`、約100KB）
- **言語・ライブラリ**: HTML5, Vanilla JavaScript (ES5/ES6), CSS3（フレームワーク・ビルドツールなし）

## 8. UX方針
- **挫折させない親切さ**:
  - 遅れても責めない（「たまっている分」に優しく退避）。
  - 読めなかった日があっても、今日開いたこと自体を肯定する励ましのメッセージ。
- **起動直後の即応性（0タップ・スクロール不要）**:
  - ホーム画面アイコンから起動した瞬間に、今日の箇所が画面中央にあり、1タップでチェックできる。
- **本文へのスムーズな動線**:
  - prs.app（ともに聴く聖書・新改訳2017）へ直接飛べる外部リンク。
- **省スペースと操作感**:
  - 画面の狭いiPhoneでも親指で届く浮遊ピルナビゲーション。

## 11. 既知の問題
1. **データの端末ローカル性**: `localStorage` にのみ保存されているため、端末紛失やブラウザデータ削除時に進捗が失われる。
2. **聖書箇所リンクの表記ゆれ**: `BOOK_CODE_MAP` で66巻を網羅しているが、複雑な章句（複数章またぎ等）では最初の章が開く仕様。

## 14. 注意すべき設計判断
- **「スタンプカレンダーと実績バッジを廃止した経緯」**:
  過去に一度実装されたが、UIが煩雑になりすぎたため削除され、現在の1行統計＋「庭の成長」に洗練された。安易にバッジ機能などを復活させないこと。
- **「単一ファイルHTMLの維持」**:
  `index.html` にすべて収まっているため、不用意に全体置換を行わず、必要な関数・CSSクラスのみをピンポイントで編集すること。
- **「セーフエリアとピルバー」**:
  iPhoneでのホーム画面表示（WebClip）を主眼としているため、ステータスバーの余白（`env(safe-area-inset-top)`）やピルバーのタッチ領域を崩さないこと。
